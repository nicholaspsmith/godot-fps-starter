# Godot FPS Starter

A complete, modern first-person shooter starter for **Godot 4.6** — free, permissively
licensed, and built to be the foundation of your next FPS instead of a throwaway demo.

> **Status: in development.** The design spec lands first, then the implementation.
> See [`docs/`](docs/) for the design and plan.

## Why this exists

Unreal ships an excellent first-person template in the box. Godot does not. New Godot
developers who want to build a shooter end up stitching together half-finished tutorials,
and the result is usually a monolithic `player.gd` they outgrow in a month.

This project aims to be the thing that should already exist: a starter with real gunplay
feel, a real enemy, a real UI shell, and an architecture that still holds up once your
game gets big.
